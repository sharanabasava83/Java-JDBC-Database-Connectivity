# Java JDBC Database Connectivity

## 📌 Objective
This project demonstrates how to connect a Java application to a MySQL database using JDBC and perform CRUD operations.

## 🛠 Technologies Used
- Java
- JDBC
- MySQL

## 📂 Features
- Database Connection
- Insert Record
- Retrieve Records
- Update Record
- Delete Record

## ▶ How to Run
1. Install MySQL
2. Create database using database_setup.sql
3. Update password in DatabaseApp.java
4. Compile:
   javac -cp "lib/*" src/DatabaseApp.java
5. Run:
   java -cp "lib/*;src" DatabaseApp
